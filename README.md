# Sign Talk — AI อ่านตัวอักษรภาษามือ (ASL A–Z)

**ลองใช้ได้เลย:** https://ohmomega.github.io/AI-sign-language-/ (เปิดในเบราว์เซอร์บนมือถือหรือคอมที่มีกล้อง ไม่ต้องติดตั้งอะไร)


เว็บแอปช่วยคุยกับคนที่ใช้ภาษามือแบบสะกดตัวอักษร

- **อ่านภาษามือ:** ชูมือหน้ากล้อง → AI อ่านเป็นตัวอักษร พิมพ์ต่อเป็นคำ และอ่านออกเสียงได้
- **ตอบกลับ:** พิมพ์ข้อความ → แอปโชว์ท่ามือของแต่ละตัวอักษร (เต็มจอทีละตัวได้)
- **ท่ามือ A–Z:** ตารางท่ามือไว้ฝึก โดยใช้รูปจาก dataset ที่ถ่ายเอง

ทุกอย่างประมวลผลในเบราว์เซอร์ ไม่มีการส่งภาพจากกล้องไปที่ไหน

> ข้อจำกัด: รู้จำเฉพาะ **ตัวอักษร ASL** (ภาษามืออเมริกัน) แบบท่านิ่ง ยังไม่ใช่ภาษามือเต็มรูปแบบ (คำ/ประโยค) และไม่ใช่ภาษามือไทย
> J กับ Z ของจริงต้องขยับมือ จึงอาจแม่นน้อยกว่าตัวอื่น

## วิธีทำงาน

เวอร์ชันแรก (โฟลเดอร์ `AI/`, วิชา AI ปี 2) ใช้ CNN ดูทั้งรูป 100×100 ซึ่งเรียนรู้ฉากหลังไปด้วย พอเปลี่ยนสถานที่ก็ทายผิด
เวอร์ชันนี้เปลี่ยนเป็น 2 ขั้น:

1. **MediaPipe Hand Landmarker** หาจุดข้อนิ้ว 21 จุด (ไม่สนฉากหลัง แสง สีผิว)
2. **MLP เล็กๆ** (63 → 128 → 64 → 26) จำแนกตัวอักษรจากตำแหน่งข้อนิ้ว
   - ปรับให้จุดข้อมือเป็นจุดศูนย์กลาง และย่อขยายตามขนาดฝ่ามือ
   - เพิ่มข้อมูลด้วยการกลับซ้าย/ขวา หน้า/หลังมือ หมุนเล็กน้อย → ใช้ได้ทั้งมือซ้ายและขวา

| | CNN เดิม | Sign Talk |
|---|---|---|
| ความแม่นบนรูปที่ไม่เคยเห็น (692 รูป) | ~98%\* | **98.8%** |
| รูปทดสอบจากคนอื่น ฉากหลังต่างกัน (3 รูป) | ทาย A เป็น B | **ถูก 3/3** |
| ใช้กับกล้องสด | ❌ | ✅ |

\* ตัวเลขเดิมสูงเกินจริง เพราะชุด train/validation ใช้ seed สุ่มคนละค่า ทำให้รูปซ้ำกัน

## รันในเครื่อง

```bash
cd app
python -m http.server 8000
# เปิด http://localhost:8000  (กล้องใช้ได้บน localhost หรือ https เท่านั้น)
```

## ฝึกโมเดลใหม่ (ถ้าเพิ่มรูป)

```bash
python -m venv .venv
.venv/Scripts/pip install mediapipe scikit-learn pillow numpy
# 1) ดึงจุดข้อนิ้วจากรูป (dataset/train/<A-Z>/*.jpg) — ~10 นาทีสำหรับ 3,500 รูป
.venv/Scripts/python tools/extract_landmarks.py path/to/dataset/train data/landmarks.json
# 2) ฝึก + export app/model.json และรูปท่ามือ app/signs/
.venv/Scripts/python tools/train.py data/landmarks.json path/to/dataset/train app
```

`data/landmarks.json` เก็บจุดข้อนิ้วที่ดึงแล้วไว้ ฝึกใหม่ได้โดยไม่ต้องใช้ dataset 15GB
(ยกเว้นขั้นสร้างรูปใน `app/signs/` ที่ต้องเปิดรูปต้นฉบับ)

## โครงสร้าง
